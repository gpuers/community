# GPUers Community

This repository is the public community space for readers of [GPUers](https://gpuers.cn/), a technical publication about Linux GPU drivers, DRM, memory management, virtualization, and related systems software.

## How to participate

- Use **Issues** to report article errata, broken links, or website problems.
- Use **Discussions** to ask questions, discuss an article, or suggest future topics.
- When reporting an error, please include the article URL, the relevant text or code, and a correction or supporting reference when possible.

The entry links:
- [Report an issue](https://github.com/gpuers/community/issues/new) 
- [Join a discussion](https://github.com/gpuers/community/discussions)

## Scope

This repository is for reader feedback and discussion only. Technical articles are maintained in a separate manuscript repository, so pull requests are not accepted here.

## Languages

English and Chinese are both welcome. Please keep discussions respectful and focused on technical topics.
